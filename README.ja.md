RICOHはファームウェア2.10で、GR IIIに**GF-2フラッシュモード**を追加しました。小型のRICOH GF-2フラッシュを装着すると、カメラはフラッシュを一定の発光量で発光させ、**ピント距離**から絞り、ISO感度、シャッタースピードを決めます。GR IVには、このモードは搭載されませんでした。

GR4-GF2Unlockは、このモードを、強制発光、赤目軽減強制発光、スローシンクロ、赤目軽減スローシンクロに続く**5つ目のフラッシュモードの選択肢**としてGR IVに追加します。カメラのそれ以外の部分はすべてそのままで、いつでも公式ファームウェアに戻せます。

このリポジトリにRICOHのファームウェアは含まれていません。公式ファームウェアはご自身でRICOHからダウンロードしてください。同梱のツールが、お使いのコンピューター上で、それをGF-2フラッシュモード版に作り変えます。

## 仕組み

GF-2フラッシュモードを選ぶと、カメラは強制発光と同じようにフラッシュを発光させますが、発光量は**一定**です。そのうえで、GR IIIのGF-2フラッシュモードと同じ方法で露出を決めます。つまり、フラッシュの**ガイドナンバー**と**ピント距離**（オートフォーカスでもマニュアルフォーカスでも）から、GR IV自身の絞り、ISO感度、フラッシュ同調の範囲内で露出を決めます。ガイドナンバーはGF-2の3です。ファームウェアを作るときにお使いのフラッシュのガイドナンバーを指定すれば、それが使われます（[自分のフラッシュを使う](#自分のフラッシュを使う)を参照）。

- **発光量：** GF-2の発光量は、カメラが**フラッシュ発光量**で設定します。**オートまたは1/1**ではフル発光、**1/4**では1/4の発光量になります。ほかのフラッシュは、フラッシュ本体で設定した発光量で発光します（[自分のフラッシュを使う](#自分のフラッシュを使う)を参照）。
- **ISOオートの場合、**カメラは絞りを開き、被写体が遠くなるにつれてISO感度を上げます。近い被写体では最低ISO感度のままで、距離に応じてf/16まで絞りを絞ります。
- **ISO感度を固定した場合、**カメラは距離に合った絞りを選びます。
- **シャッタースピード**は、被写体の周りの明るさに合わせて決まります。フラッシュ同調の範囲内に収まるので、フラッシュの光は必ず写真に写ります。最も遅くて1/32秒、暗い場所でスローシンクロを使う場合は最長32秒です。
- **Tv、Av、Mでは、**GR IIIと同じように、ダイヤルで設定した値よりもこのモードの値が優先されます。

露出の計算はRICOH自身のもので、GR IIIのファームウェア2.10から引き継いでいます。それ以外はすべて公式のGR IVファームウェアのままで、変更していません。

### 設定値の目安

薄暗い室内、フラッシュ発光量がオートまたは1/1、NDフィルターがオフのときの代表的な値です（EXIFでは少し丸められることがあります）。

| 距離 | ISOオート | ISO 400固定 |
| ---: | --- | --- |
| 0.5 m | f/5.9、ISO 100 | f/11.8 |
| 1 m | f/3.0、ISO 100 | f/5.9 |
| 2 m | f/2.8、ISO 367 | f/3.0 |
| 3 m | f/2.8、ISO 800 | f/2.8 |
| 5 m | f/2.8、ISO 2263 | f/2.8（被写体は暗くなる：フラッシュの届く範囲外） |

フラッシュ発光量が**1/4**の場合は、ISO感度が約2段高くなるか、絞りが約2段開きます。ほかのガイドナンバーでは、絞りもそれに比例します。F値 ＝ ガイドナンバー × √(ISO感度 ÷ 100) ÷ 距離（範囲はf/2.8〜f/16）。

> [!TIP]
> **モードが有効になっているか確認するには。** GF-2フラッシュモードを選び、露出モードを**M**、**ISO 400**、シャッタースピードを1/2000秒またはそれより遅く設定します。約1 m離れたものを撮り、次に約3 m離れたものを撮ります。ダイヤルで何を設定していても、絞りがひとりでに約f/5.9と約f/2.8に変わります。

## 得られるもの

インストール後、**フラッシュモード**（メニュー、ADJレバー、Fnボタン）には次の選択肢が表示されます。

| 表示 | フラッシュの動作 |
| --- | --- |
| 強制発光 | 毎回発光する（従来どおり） |
| 赤目軽減強制発光 | 従来どおり |
| スローシンクロ | 従来どおり |
| 赤目軽減スローシンクロ | 従来どおり |
| **GF-2フラッシュモード** | **発光量は一定。絞り、ISO感度、シャッタースピードはピント距離から決まる** |

- 新しい項目には、メニューのどの言語でも独自の表示名が付きます。たとえば日本語では「GF-2フラッシュモード」です。スローシンクロが使えない場合、選択肢は強制発光、赤目軽減強制発光、GF-2フラッシュモードになります。
- **P、Tv、Av、M**のとき、GF-2と、マニュアルフラッシュなど**カメラと通信しないどのフラッシュでも**働きます。GR IIIと同じです。露出はファームウェアに設定したガイドナンバー、つまりGF-2のもの、またはお使いのフラッシュのものに合わせて決まります（[自分のフラッシュを使う](#自分のフラッシュを使う)を参照）。
- RICOHやPENTAXのフラッシュなど、カメラと通信する**P-TTLフラッシュ**では、GF-2フラッシュモードは強制発光として働きます。これもGR IIIと同じです。
- 設定は、ほかのフラッシュモードの設定と同じく、カメラの電源を切っても保持されます。
- 撮影画面には**強制発光**のアイコンが表示され、写真には強制発光と同じく、フラッシュが発光したことが記録されます。
- **ほかのフラッシュモードは、すべて従来どおり動作します。** フラッシュ発光量のオート、1/1、1/4も同様です。

### GR IIIのオリジナルより優れている点

RICOHの露出計算はそのままに、その周りでGR IV版はGR IIIにはないハードウェアを活用し、いくつかの弱点を修正しています。

| | GR III 2.10 | GR4-GF2Unlock |
| --- | --- | --- |
| 発光量 | フル発光のみ：GR IIIはGF-2を制御できない | GF-2では、フル発光または1/4の発光量（フラッシュ発光量1/1または1/4）。それぞれに合わせて露出を計算 |
| ガイドナンバー | 常に3（GF-2のもの） | 3、またはお使いのフラッシュのもの（1〜90） |
| ISOオートでの近い被写体 | 0.7 mより近いと、最大で約1 EV明るくなる | 距離に応じた絞り（f/16まで） |
| ISOオートでNDフィルターがオン | 背景が2段暗く写る | シャッタースピードがNDフィルターを考慮するので、背景が適正露出になる |
| 明るい場所でのごく近い被写体 | レンズの最小絞りf/16を超えるf/19を要求することがある | f/2.8〜f/16の範囲内に収まる |
| フラッシュ同調 | フラッシュ同調より速いシャッタースピードを要求することがある | 常にフラッシュ同調の範囲内（GR IVでは同調速度が絞りによって変わる） |
| それ以外すべて | モードをオンにすると、通常のフラッシュの動作が置き換わる | 5つあるフラッシュモードの選択肢の1つ。いつでも強制発光に戻し、GR IVの自動のフラッシュ発光量で撮影できる |

距離、ISO感度、NDフィルター、フラッシュモード、明るさ、フラッシュの種類、ガイドナンバー（1〜90）の組み合わせを250,000通り以上確認しました。f/2.8〜f/16の範囲外の絞りや、設定した上限・下限の範囲外のISO感度、フラッシュが同調できないシャッタースピードを要求する組み合わせは1つもありません。

## はじめる前に

- **カメラ：** RICOH GR IV（標準のカラーモデル）。ほかの機種には対応していません。
- **フラッシュ：** RICOH GF-2、またはガイドナンバーがわかるマニュアルフラッシュ（[自分のフラッシュを使う](#自分のフラッシュを使う)を参照）。ほかのフラッシュモードは、どのフラッシュでも従来どおり動作します。
- **カメラのファームウェアがすでに1.11である必要があります。** バージョンはカメラのセットアップメニューで確認してください。
  - 古いバージョンの場合：まずRICOHの公式ファイルを使い、通常の方法で1.11にアップデートしてください。
  - 新しいバージョンの場合：**このツールは使わないでください。** 対応しているのは1.11だけです。
- **公式ファームウェアファイル。** RICOH IMAGINGの公式GR IVサポートページから、**ファームウェアバージョン1.11**をダウンロードします。必要に応じて展開し、**`fwdc248b.bin`** というファイルを取り出します。
- **満充電のバッテリー。** ファームウェアアップデート中に電源が切れることは絶対に避けてください。
- フォーマットしてもよい**SDカード**。
- **Python 3.8以降が入ったコンピューター。** macOSとほとんどのLinuxシステムには、すでに入っています。Windowsでは、python.orgからインストールしてください。ほかには何も必要ありません。
- 設定し直したくないカスタム設定（C1、C2など）は控えておいてください。

## ファームウェアを作る

このフォルダでターミナルを開き、次を実行します（公式ファイルを保存した場所のパスを使ってください）。

```sh
python3 gr4_gf2unlock.py patch ~/Downloads/fwdc248b.bin
```

Windowsでは：

```bat
py gr4_gf2unlock.py patch C:\Users\you\Downloads\fwdc248b.bin
```

ツールはまず、渡されたファイルが本物の公式1.11ファイルであることを確認します。それからGF-2フラッシュモードのファームウェアを作成して確認します。これには1分ほどかかります。すべて正しければ、最後は次のようになります。

```
wrote output/fwdc248b.bin  (SHA-256 86abac009d3664ede49ef912073d00b8fb15ac7e9867265aecda581c932db41a)
```

問題がある場合、ツールは`refused: …`と表示し、**何も書き出しません**。たとえば、ファームウェアのバージョンが違う、すでに改変されたファイルである、ダウンロードしたファイルが壊れている、といった場合です。

### 自分のフラッシュを使う

GF-2フラッシュモードは、GF-2のガイドナンバー3に合わせて露出を決めます。ほかのフラッシュを使うには、`--gn`でそのガイドナンバーを指定します。

```sh
python3 gr4_gf2unlock.py patch ~/Downloads/fwdc248b.bin --gn 12
```

- **対応するフラッシュ：** カメラと通信せず、ホットシューの中央接点で発光するフラッシュです。マニュアルフラッシュや、ほかのカメラメーカー向けのほとんどのフラッシュが当てはまります。P-TTLフラッシュや、P-TTLモードにした互換フラッシュはカメラと通信します。その場合、GF-2フラッシュモードはGR IIIと同じく強制発光として働きます。
- ガイドナンバーは、フラッシュの取扱説明書にある、フル発光時の**ISO 100、メートル単位**の値を指定してください。フィート単位の場合は3.3で割ります。ズームできるフラッシュの場合は、撮影するズーム位置のガイドナンバーを使ってください。
- 指定できる範囲は**1〜90**です。カメラは1/16段刻みで動作するため、ツールは実際に使う値を表示します。たとえば12なら`guide number: 11.81`と表示されます。
- **カメラは、このようなフラッシュの発光量を設定できません。** フラッシュを**フル発光のマニュアル**に、フラッシュ発光量を**オート**または**1/1**に設定してください。代わりにフラッシュを1/4の発光量にする場合は、フラッシュ発光量も**1/4**に設定してください。カメラは2段少ない発光量として露出を決めます。
- ツールはまず標準のファームウェアを作って上記のように確認し、そのあとガイドナンバーだけを書き換えます。そのため、SHA-256は上記のものとは異なります。ファイルのガイドナンバーは`check`で確認できます。
- ガイドナンバーを変えるには、ファームウェアを作り直してインストールし直してください。

## カメラに入れる

### 1. SDカードにコピーする

1. **カメラでSDカードをフォーマットします。**
2. **`output/fwdc248b.bin`** をカードの**最上位**にコピーします。フォルダの中には入れず、名前は`fwdc248b.bin`のまま変えないでください。

### 2. カメラをアップデートする

1. 満充電のバッテリーとSDカードを入れます。
2. RICOHの公式GR IVファームウェアアップデート手順に従い、カメラのセットアップメニューからファームウェアアップデートを開始します。
3. **カメラには、バージョン1.11からバージョン1.11へのアップデートと表示されます。** これは想定どおりです。GF-2フラッシュモードのファームウェアはバージョン番号をそのまま保ちます。アップデートを確定してください。

> [!CAUTION]
> アップデートが完了してカメラが再起動するまで、**カメラの電源を切ったり、バッテリーカバーやカードカバーを開けたり、カードを取り出したりしないでください。**

### 3. 撮影する

1. カメラとGF-2の両方の電源が**切れている**状態で、GF-2をホットシューの奥までしっかり差し込み、それから両方の電源を入れます。
2. 撮影設定メニュー → **フラッシュモード** → **GF-2フラッシュモード**を選びます。
3. **フラッシュ発光量**を、フル発光なら**オート**または**1/1**に、あるいは**1/4**に設定します。
4. 被写体にピントを合わせて撮影します。

- ファームウェアのバージョンは**1.11**のままです。これは正常です。
- 誤ってアップデートが再び始まらないように、カードから`fwdc248b.bin`を削除してください（またはカードをフォーマットします）。

### 公式ファームウェアに戻す

> [!IMPORTANT]
> **まず、フラッシュモードをGF-2フラッシュモード以外に設定してください。** たとえば強制発光にします。GF-2フラッシュモードを使っているすべてのカスタムモード（C1、C2など）でも同じようにします。公式ファームウェアにはGF-2フラッシュモードの設定がありません。

その後、代わりにRICOHの**公式** `fwdc248b.bin` を使って、手順1〜2を繰り返します。カメラにはまた**1.11 → 1.11**と表示されます。確定すれば、カメラは元の状態に戻ります。

## 知っておきたいこと

- **フラッシュを付け外しする前に、カメラとGF-2の電源を切ってください。** また、GF-2はホットシューの奥までしっかり差し込んでください。
- **カメラは、フラッシュが発光するかどうかを判別できません。** GF-2フラッシュモードを選んでいると、フラッシュの電源が切れている、装着されていない、充電中といった場合でも、カメラはフラッシュ撮影用の露出を設定します。その写真は暗くなりすぎます。これはGR IIIでも同じです。
- **強力なフラッシュでの近距離撮影：** 被写体がとても近く、最低ISO感度のf/16でもフラッシュの光が多すぎる場合、写真は計画より明るく写ります。ISOオートでNDフィルターをオートにしていると、約1段明るすぎる状態になった時点でカメラがNDフィルターを使います。そうでない場合は、フラッシュ発光量を1/4にするか、被写体から離れてください。
- **ISO感度固定で遠い被写体：** 絞りが開放（f/2.8）になると、それより遠い被写体は暗くなります。ISO感度を上げるか、ISOオートを使ってください。
- **明るい日中：** シャッタースピードはフラッシュ同調より速くできません（f/2.8〜f/4で1/2500秒）。NDフィルターをオートにしておくと、それよりずっと明るい場合、カメラはNDフィルターを使います。このときフラッシュは補助光として働きます。
- **連続撮影：** GR IIIとは違い、フラッシュの充電を自動で待つ機能はありません。フラッシュ撮影の間は2秒ほど空けてください。
- **スナップ距離優先AE、B、T、動画**は従来どおり動作します。これらにはGF-2フラッシュモードは適用されません。
- **GR4-MonoUnlockやGR4-XPanUnlockとは組み合わせられません。** どのツールも公式ファームウェアから作るもので、このツールはそれらのファイルを受け付けません。
- **以前のGR4-GF2Unlockからのアップデート：** 新しいファイルを同じ方法でインストールしてください。先に公式ファームウェアに戻す必要はありません。バージョン1.1.0と1.2.0では、GF-2フラッシュモードはカメラが検出したフラッシュにしか適用されなかったため、マニュアルフラッシュでは効果がありませんでした。1.3.0でこれを修正しました。
- **RICOHの公式アップデートで、GF-2フラッシュモードは消えます。** ファームウェア全体が置き換わるためです。先にほかのフラッシュモードに設定してください（[公式ファームウェアに戻す](#公式ファームウェアに戻す)を参照）。
- **標準のGR IV専用です。** ほかの機種には絶対にインストールしないでください。
- **カメラを修理に出す前に**、公式ファームウェアに戻してください。

### ファームウェアファイルを確認

ファームウェアファイルをカードにコピーする前に確認してください。

```sh
python3 gr4_gf2unlock.py check path/to/fwdc248b.bin
```

ファイルが公式の1.11か、このツールで作ったGF-2フラッシュモード版（ガイドナンバーも表示されます）か、それ以外かがわかります（GR4-GF2Unlock 1.0.0、1.1.0、1.2.0、GR4-MonoUnlock、GR4-XPanUnlockのファイルも識別できます）。

## リスク

- カメラは、正常なファームウェアファイルと壊れたファイルを見分けられません。カードにコピーするのは、このツールが書き出した（または`check`で確認した）ファイルだけにしてください。
- アップデートが中断された場合や、ファームウェアファイルが起動できない場合、カメラがアップデート機能に再びたどり着けなくなり、RICOHの修理が必要になる可能性があります。テストではこのようなことは起きていませんが、可能性は否定できません。
- GF-2フラッシュモードを選んだまま公式ファームウェアに戻すことは、テストしていません。先にほかのフラッシュモードに設定してください。
- カメラ固有のキャリブレーションデータには手を加えません。
