RICOH 在固件 2.10 中为 GR III 加入了 **GF-2闪光灯模式**：装上小巧的 RICOH GF-2 闪光灯后，相机以固定功率闪光，并根据 **对焦距离** 算出光圈、ISO 和快门速度。GR IV 一直没有得到这个模式。

GR4-GF2Unlock 把它作为 **第五个闪光灯模式选项** 加入 GR IV，与强制闪光、强制闪光+消减红眼、低速同步和低速同步+消减红眼并列。相机上的其他一切都保持原样，你可以随时恢复官方固件。

本仓库不包含任何 RICOH 固件。官方固件由你自己从 RICOH 下载，附带的工具会在你自己的电脑上把它转换成 GF-2闪光灯模式版本。

## 工作原理

选择 GF-2闪光灯模式后，相机会像强制闪光一样触发闪光灯，但使用 **固定功率**。然后它按照 GR III 的 GF-2闪光灯模式的方式规划曝光：根据闪光灯的 **闪光指数** 和 **对焦距离**（自动对焦或手动对焦），在 GR IV 自身的光圈、ISO 和闪光同步限制范围内进行计算。闪光指数取 GF-2 的 3，除非你在制作固件时给出自己闪光灯的闪光指数（见[使用你自己的闪光灯](#使用你自己的闪光灯)）。

- **功率：** 相机通过 **闪光量** 设定 GF-2 的功率：**自动或 1/1** 为全功率，**1/4** 为四分之一功率。其他闪光灯按闪光灯本身设定的功率闪光（见[使用你自己的闪光灯](#使用你自己的闪光灯)）。
- **使用 ISO 自动时，** 相机开大光圈，并随着被摄体变远而提高 ISO。近距离时保持最低 ISO，并按距离所需收小光圈，最小到 f/16。
- **使用固定 ISO 时，** 相机选择适合该距离的光圈。
- **快门速度** 取决于被摄体周围的光线。它始终在闪光同步范围内，因此闪光一定会出现在照片中。最慢为 1/32 秒；在暗处使用低速同步时，最长可达 32 秒。
- **在 Tv、Av 和 M 模式下，** 你设定的数值会被覆盖，与 GR III 相同。
- **ND滤光镜设为自动时，** 强光下的曝光也保持正常。当光圈和快门速度无法维持正常曝光时，相机会先降低 ISO（ISO 自动），再收小光圈，然后加入 ND滤光镜（见[强光下](#强光下nd滤光镜自动)）。

曝光计算是 RICOH 自己的，沿用自 GR III 的固件 2.10。其他一切都是未经改动的官方 GR IV 固件。

### 预期效果

在昏暗的室内、闪光量为自动或 1/1、ND滤光镜关闭时的典型数值（EXIF 中的数值可能略有取整）：

| 距离 | ISO 自动 | 固定 ISO 400 |
| ---: | --- | --- |
| 0.5 m | f/5.9，ISO 100 | f/11.8 |
| 1 m | f/3.0，ISO 100 | f/5.9 |
| 2 m | f/2.8，ISO 367 | f/3.0 |
| 3 m | f/2.8，ISO 800 | f/2.8 |
| 5 m | f/2.8，ISO 2263 | f/2.8（被摄体偏暗：超出闪光范围） |

闪光量为 **1/4** 时，ISO 约高两档，或光圈约大两档。使用其他闪光指数时，光圈随之变化：光圈值 = 闪光指数 × √(ISO / 100) ÷ 距离，范围 f/2.8–f/16。

> [!TIP]
> **确认该模式已生效。** 选择 GF-2闪光灯模式，设为 **M** 模式、**ISO 400**，快门速度设为 1/2000 秒或更慢。先拍约 1 m 远的物体，再拍约 3 m 远的物体。无论你设定的是什么，光圈都会自动变化，分别约为 f/5.9 和 f/2.8。

## 安装后的效果

安装后，**闪光灯模式**（在菜单、ADJ 拨杆和 Fn按钮 中）提供以下选项：

| 显示为 | 闪光灯的行为 |
| --- | --- |
| 强制闪光 | 每次拍摄都闪光，与以前相同 |
| 强制闪光+消减红眼 | 与以前相同 |
| 低速同步 | 与以前相同 |
| 低速同步+消减红眼 | 与以前相同 |
| **GF-2闪光灯模式** | **固定功率；根据对焦距离确定光圈、ISO 和快门速度** |

- 新选项在每种菜单语言中都有自己的名称，例如简体中文中的“GF-2闪光灯模式”。无法使用低速同步时，可选项为强制闪光、强制闪光+消减红眼和 GF-2闪光灯模式。
- 它在 **P、Tv、Av 或 M** 模式下，配合 GF-2 以及 **任何不与相机通信的闪光灯**（例如手动闪光灯）工作，与 GR III 相同。曝光是按固件中的闪光指数计算的：GF-2 的，或你自己闪光灯的（见[使用你自己的闪光灯](#使用你自己的闪光灯)）。
- 使用与相机通信的 **P-TTL 闪光灯**（例如 RICOH 或 PENTAX 闪光灯）时，GF-2闪光灯模式按强制闪光工作，这同样与 GR III 相同。
- 与其他闪光灯模式设置一样，关机后该设置会保留。
- 拍摄画面显示 **强制闪光** 图标，照片也会像强制闪光一样记录为闪光灯已闪光。
- **其他所有闪光灯模式都与以前完全相同**，包括闪光量的自动、1/1 和 1/4。

### 比 GR III 上的原版更好

在 RICOH 的曝光计算之外，GR IV 版本利用了 GR III 所没有的硬件，并修正了几处不足：

| | GR III 2.10 | GR4-GF2Unlock |
| --- | --- | --- |
| 闪光功率 | 只有全功率：GR III 无法控制 GF-2 | 使用 GF-2 时，全功率或四分之一功率（闪光量 1/1 或 1/4），并分别计算曝光 |
| 闪光指数 | 始终为 3，即 GF-2 的 | 3，或你自己闪光灯的（1 到 90） |
| ISO 自动时的近距离被摄体 | 0.7 m 以内最多偏亮约 1 EV | 按距离所需的光圈，最小到 f/16 |
| ISO 自动且 ND滤光镜开启 | 背景会暗两档 | 快门速度考虑了 ND滤光镜，因此背景曝光正确 |
| 强光下的极近被摄体 | 可能要求 f/19，超出镜头的 f/16 | 保持在 f/2.8–f/16 之内 |
| 强光下，ND滤光镜自动 | 最多偏亮一档，之后 ND滤光镜又会使闪光弱两档 | 先降低 ISO，再收小光圈，最后加入 ND滤光镜：照片曝光正确，闪光只损失不得不舍去的那部分光 |
| 近距离被摄体，ND滤光镜自动 | 固定 ISO 时即使 f/16 也过亮 | 加入 ND滤光镜，并相应开大光圈 |
| 闪光同步 | 可能要求比闪光同步更快的快门速度 | 始终在闪光同步范围内，而 GR IV 的闪光同步取决于光圈 |
| 其他一切 | 开启该模式会取代正常的闪光行为 | 五个闪光灯模式选项之一：随时可以切回强制闪光和 GR IV 的自动闪光量 |

已检查了超过 250,000 种距离、ISO、ND滤光镜、闪光灯模式、光线、闪光灯类型和闪光指数（1 到 90）的组合。没有任何一种组合会要求超出 f/2.8–f/16 的光圈、超出你所设限制的 ISO，或闪光灯无法同步的快门速度。

## 开始之前

- **相机：** RICOH GR IV（标准彩色型号）。不支持其他型号。
- **闪光灯：** RICOH GF-2，或你知道其闪光指数的手动闪光灯（见[使用你自己的闪光灯](#使用你自己的闪光灯)）。其他闪光灯模式与所有闪光灯照常配合工作。
- **相机必须已升级到固件 1.11。** 请在相机的设定菜单中查看版本。
  - 较旧版本：先用 RICOH 的官方文件按常规方式更新到 1.11。
  - 较新版本：**不要使用本工具。** 它只支持 1.11。
- **官方固件文件。** 从 RICOH IMAGING 官方的 GR IV 支持页面下载 **固件版本 1.11**。如有需要请解压，直到得到文件 **`fwdc248b.bin`**。
- **充满电的电池。** 固件更新过程中绝不能断电。
- **一张可以格式化的 SD 卡。**
- **一台装有 Python 3.8 或更高版本的电脑。** macOS 和大多数 Linux 系统已经自带；在 Windows 上，请从 python.org 安装。不需要其他任何东西。
- 记下你不想重新设置的自定义设置（C1、C2 等）。

## 制作固件

在此文件夹中打开终端并运行（请换成你保存官方文件的路径）：

```sh
python3 gr4_gf2unlock.py patch ~/Downloads/fwdc248b.bin
```

在 Windows 上：

```bat
py gr4_gf2unlock.py patch C:\Users\you\Downloads\fwdc248b.bin
```

工具会先确认你提供的是真正的官方 1.11 文件，然后生成 GF-2闪光灯模式固件并进行检查。这大约需要一分钟。一切正常时，它会这样结束：

```
wrote output/fwdc248b.bin  (SHA-256 ab00b2487126b4ab14e4872288970bb4a51f99ef7b56e57356a9603da6778bec)
```

如果出现问题，它会显示 `refused: …`，并且 **不写入任何内容**：例如固件版本不同、文件已被修改过，或下载的文件已损坏。

### 使用你自己的闪光灯

GF-2闪光灯模式按 GF-2 的闪光指数 3 规划曝光。要使用其他闪光灯，请用 `--gn` 加上它的闪光指数：

```sh
python3 gr4_gf2unlock.py patch ~/Downloads/fwdc248b.bin --gn 12
```

- **适用的闪光灯：** 任何不与相机通信、通过热靴中心触点触发的闪光灯：手动闪光灯，以及大多数为其他相机品牌设计的闪光灯。P-TTL 闪光灯，或处于 P-TTL 模式的兼容闪光灯，会与相机通信；此时 GF-2闪光灯模式按强制闪光工作，与 GR III 相同。
- 请从闪光灯说明书中查出全功率时 **ISO 100、以米为单位** 的闪光指数。以英尺为单位的闪光指数：除以 3.3。变焦闪光灯：使用你拍摄时的变焦设置所对应的闪光指数。
- 允许范围：**1 到 90**。相机以 1/16 档为步长工作，工具会显示实际使用的值，例如 12 对应 `guide number: 11.81`。
- **相机无法设定这类闪光灯的功率。** 请把闪光灯设为 **全手动功率**，并把闪光量设为 **自动** 或 **1/1**。如果改为把闪光灯设为 1/4 功率，请把闪光量也设为 **1/4**：相机随后会按少两档来规划。
- 工具会先制作标准固件并如上检查，然后只修改闪光指数。此时的 SHA-256 与上面的不同；`check` 会显示文件的闪光指数。
- 要更改闪光指数，请重新制作固件并安装。

## 安装到相机

### 1. 复制到 SD 卡

1. **在相机中格式化 SD 卡。**
2. 把 **`output/fwdc248b.bin`** 复制到存储卡的 **根目录**：不要放进文件夹，文件名必须保持为 `fwdc248b.bin`。

### 2. 更新相机

1. 装入充满电的电池和 SD 卡。
2. 按照 RICOH 官方 GR IV 固件更新说明，从相机的设定菜单启动固件更新。
3. **相机会显示从版本 1.11 更新到版本 1.11。** 这是正常的：GF-2闪光灯模式固件保留了版本号。请确认更新。

> [!CAUTION]
> **在更新完成且相机重新启动之前，不要关闭相机、不要打开电池仓盖或存储卡盖，也不要取出存储卡。**

### 3. 拍摄

1. 在相机和 GF-2 都 **关闭** 的状态下，把 GF-2 完全插入热靴，然后打开两者的电源。
2. 拍摄设定菜单 → **闪光灯模式** → **GF-2闪光灯模式**。
3. 把 **闪光量** 设为 **自动** 或 **1/1**（全功率），或设为 **1/4**。
4. 对焦到被摄体上并拍摄。

- 固件版本仍显示 **1.11**。这是正常的。
- 从存储卡中删除 `fwdc248b.bin`（或格式化存储卡），以免意外再次启动更新。

### 恢复官方固件

> [!IMPORTANT]
> **先把闪光灯模式设为 GF-2闪光灯模式以外的任意选项**，例如强制闪光，并在每个使用它的自定义模式（C1、C2 等）中同样设置。官方固件没有 GF-2闪光灯模式设置。

然后改用 RICOH 的 **官方** `fwdc248b.bin`，重复第 1–2 步。相机同样会显示 **1.11 → 1.11**；确认后，相机即恢复为原厂状态。

## 须知

- **装上或取下闪光灯之前，请关闭相机和 GF-2 的电源**，并把 GF-2 完全推入热靴。
- **相机无法判断闪光灯是否会闪光。** 选择 GF-2闪光灯模式时，即使闪光灯已关闭、未装上或仍在回电，相机也会按闪光照片设定曝光。这样拍出的照片会过暗。GR III 上也是如此。
- **功率大的闪光灯近距离使用：** 当被摄体近到即使在最低 ISO 下 f/16 也会让过多闪光进入时，若 ND滤光镜设为自动，相机会加入 ND滤光镜，并相应开大光圈。若 ND滤光镜关闭，或被摄体更近，照片会比规划的更亮：请使用闪光量 1/4，或后退几步。
- **固定 ISO 与远处的被摄体：** 光圈一旦全开（f/2.8），被摄体越远就越暗。请提高 ISO，或使用 ISO 自动。
- **明亮的日光下：** 快门速度不能快于闪光同步（f/2.8–f/4 时为 1/2500 秒，f/5.6 起为 1/4000 秒）。见下文[强光下](#强光下nd滤光镜自动)。
- **连拍：** 与 GR III 不同，不会自动等待闪光灯回电。两次闪光拍摄之间请间隔约两秒。
- **快拍距离优先自动曝光、B 和 T 以及视频** 与以前相同。GF-2闪光灯模式在这些情况下不起作用。
- **不能与 GR4-MonoUnlock 或 GR4-XPanUnlock 组合使用。** 每个工具都从官方固件开始，而本工具会拒绝它们的文件。
- **从早期的 GR4-GF2Unlock 更新：** 用同样的方法安装新文件即可，无需先恢复官方固件。1.1.0 和 1.2.0 版本只对相机能检测到的闪光灯应用 GF-2闪光灯模式，因此搭配手动闪光灯时不起作用；1.3.0 修正了这一点。1.4.0 加入了 ND滤光镜设为自动时的强光处理。
- **RICOH 官方更新会移除 GF-2闪光灯模式。** 它会替换整个固件。请先设置其他闪光灯模式（见[恢复官方固件](#恢复官方固件)）。
- **仅适用于标准版 GR IV。** 切勿在其他型号上安装该文件。
- **送修相机之前，** 请恢复官方固件。

### 强光下（ND滤光镜自动）

在强光下，快门速度会达到闪光同步的极限，而 GF-2闪光灯模式为闪光选定的光圈会让过多的日光进入。**ND滤光镜设为自动**（拍摄设定菜单）时，相机按以下顺序使曝光保持正常：

1. **ISO 自动：** 降低 ISO，最低到你设定的下限。光圈不变。
2. 收小光圈，最小到 f/16。
3. 当 f/16 配合最快的闪光同步速度仍然过亮，或仅闪光本身在 f/16 下就已过强时，加入 **ND滤光镜**（2 档）。然后在光线允许的范围内重新开大光圈。

这样背景就能曝光正确。闪光相对于曝光保持其规划的强度，只减去日光迫使舍去的部分：在阳光下，闪光灯起补光作用。阳光下（约 EV 15）、闪光量为自动或 1/1、ND滤光镜自动时的典型数值，括号中为 ND滤光镜关闭时不同的数值：

| 距离 | ISO 自动 | 固定 ISO 400 | 固定 ISO 3200 |
| ---: | --- | --- | --- |
| 0.3 m | f/11.8，ISO 100 | f/9.9，加 ND（f/16，闪光过亮） | f/16，加 ND，仍然过亮（f/16，闪光严重过亮） |
| 1 m | f/3.7，ISO 100（f/3.5，过亮） | f/5.9 | f/8.4，加 ND（f/16，闪光过亮） |
| 3 m | f/3.7，ISO 100（f/3.4，ISO 141，过亮） | f/5.7（f/2.8，过亮） | f/16（f/5.7，过亮） |

- ND滤光镜为 **开启** 或 **关闭** 时，GF-2闪光灯模式与 1.3.0 中相同：相机不会为日光调整 ISO 或光圈，阳光下的背景可能会过亮。
- 这需要 ND滤光镜，因此适用于标准版 GR IV。GR IV HDF 没有 ND滤光镜：其固件始终把 ND滤光镜视为关闭，因此在该机型上没有任何变化。

### 检查固件文件

将任何固件文件复制到存储卡之前：

```sh
python3 gr4_gf2unlock.py check path/to/fwdc248b.bin
```

它会告诉你该文件是官方 1.11、由本工具制作的 GF-2闪光灯模式版本（含其闪光指数），还是其他文件（它也能识别 GR4-GF2Unlock 1.0.0 至 1.3.0、GR4-MonoUnlock 和 GR4-XPanUnlock 的文件）。

## 风险

- 相机无法区分完好的固件文件和损坏的文件。只把工具写出的（或经 `check` 确认的）文件复制到存储卡。
- 如果更新被中断，或固件文件无法启动，相机可能无法再进入更新功能，届时就需要 RICOH 维修。测试中没有发生过这种情况，但不能排除。
- 在仍选择 GF-2闪光灯模式的情况下恢复官方固件尚未测试过。请先设置其他闪光灯模式。
- 相机自身的校准数据不会被改动。
