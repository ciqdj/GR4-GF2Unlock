RICOH 在韌體 2.10 中為 GR III 加入了 **GF-2閃光燈模式**：裝上小巧的 RICOH GF-2 閃光燈後，相機會以固定的輸出擊發閃光燈，並依**對焦距離**計算光圈、ISO 和快門速度。GR IV 從未獲得這個模式。

GR4-GF2Unlock 為 GR IV 加入此模式，作為**閃光燈模式的第五個選項**，與強制閃光、強制閃光+消減紅眼、低速同步和低速同步+消減紅眼並列。相機的其他一切都維持原樣，而且隨時都能還原為官方韌體。

本儲存庫不含任何 RICOH 韌體。官方韌體由您自行從 RICOH 下載，再由隨附的工具在您自己的電腦上，將它轉換成 GF-2閃光燈模式版本。

> [!WARNING]
> **非官方工具，風險自負。** 並非由 RICOH IMAGING 製作或認可。安裝修改過的韌體可能導致保固失效。請先閱讀[開始之前](#開始之前)和[風險](#風險)。

## 運作原理

選擇 GF-2閃光燈模式時，相機會像強制閃光一樣擊發閃光燈，但採用**固定輸出**。接著，它以 GR III 的 GF-2閃光燈模式相同的方式規劃曝光：根據閃光燈的**閃光指數**和**對焦距離**（自動對焦或手動對焦），並且不超出 GR IV 本身的光圈、ISO 和閃光同步限制。閃光指數採用 GF-2 的 3，除非您在製作韌體時指定自己閃光燈的閃光指數（見[使用自己的閃光燈](#使用自己的閃光燈)）。

- **輸出：** 相機以**閃光量**設定 GF-2：**自動或 1/1** 為全光輸出，**1/4** 為四分之一輸出。其他閃光燈則以閃光燈本身設定的輸出擊發（見[使用自己的閃光燈](#使用自己的閃光燈)）。
- **使用 ISO 自動時，**相機會開大光圈，並隨主體距離變遠而提高 ISO。主體很近時，它會維持最低 ISO，並依距離所需縮小光圈，最小到 f/16。
- **使用固定 ISO 時，**相機會選擇適合該距離的光圈。
- **快門速度**依主體周圍的光線而定。它始終保持在閃光同步範圍內，因此閃光一定會出現在照片中。最慢為 1/32 秒；在暗處使用低速同步時，最長可達 32 秒。
- **在 Tv、Av 和 M 模式下，**您設定的數值會被覆寫，與 GR III 相同。

曝光計算採用 RICOH 自己的演算法，沿用自 GR III 的韌體 2.10。其他一切都是未經更動的官方 GR IV 韌體。

### 預期結果

昏暗室內的典型數值，閃光量為自動或 1/1，ND濾光鏡關閉（EXIF 可能會稍微四捨五入）：

| 距離 | ISO 自動 | 固定 ISO 400 |
| ---: | --- | --- |
| 0.5 m | f/5.9，ISO 100 | f/11.8 |
| 1 m | f/3.0，ISO 100 | f/5.9 |
| 2 m | f/2.8，ISO 367 | f/3.0 |
| 3 m | f/2.8，ISO 800 | f/2.8 |
| 5 m | f/2.8，ISO 2263 | f/2.8（主體較暗：超出閃光範圍） |

閃光量為 **1/4** 時，ISO 約高兩級，或光圈約大兩級。使用其他閃光指數時，光圈會隨之改變：光圈值 = 閃光指數 × √(ISO / 100) ÷ 距離，範圍在 f/2.8–f/16 之內。

> [!TIP]
> **確認模式已啟用。** 選擇 GF-2閃光燈模式，設定為 **M** 模式、**ISO 400**，快門速度為 1/2000 秒或更慢。先拍攝約 1 m 外的物體，再拍攝約 3 m 外的物體。無論您設定的是多少，光圈都會自動改變，分別約為 f/5.9 和 f/2.8。

## 您會得到什麼

安裝後，**閃光燈模式**（在選單中、ADJ 撥桿和 Fn按鈕上）提供：

| 顯示名稱 | 閃光燈的動作 |
| --- | --- |
| 強制閃光 | 每次拍攝都閃光，與先前相同 |
| 強制閃光+消減紅眼 | 與先前相同 |
| 低速同步 | 與先前相同 |
| 低速同步+消減紅眼 | 與先前相同 |
| **GF-2閃光燈模式** | **固定輸出；光圈、ISO 和快門速度依對焦距離決定** |

- 新項目在每種選單語言中都有自己的名稱，例如英文為「GF-2 Flash Mode」。無法使用低速同步時，選項為強制閃光、強制閃光+消減紅眼和 GF-2閃光燈模式。
- 它適用於 **P、Tv、Av 或 M** 模式，可搭配 GF-2 以及**任何不與相機通訊的閃光燈**（例如手動閃光燈），與 GR III 相同。曝光是依韌體中的閃光指數計算的：GF-2 的閃光指數，或您自己閃光燈的閃光指數（見[使用自己的閃光燈](#使用自己的閃光燈)）。
- 搭配與相機通訊的 **P-TTL 閃光燈**（例如 RICOH 或 PENTAX 閃光燈）時，GF-2閃光燈模式的運作與強制閃光相同，這點也與 GR III 相同。
- 相機關機後設定仍會保留，與其他閃光燈模式設定相同。
- 拍攝畫面顯示**強制閃光**圖示，照片也會記錄為已閃光，與強制閃光相同。
- **其他所有閃光燈模式的運作都與先前完全相同**，包括閃光量的自動、1/1 和 1/4。

### 比 GR III 原版更好

在 RICOH 的曝光計算之外，GR IV 版本運用了 GR III 所沒有的硬體，並修正了幾個弱點：

| | GR III 2.10 | GR4-GF2Unlock |
| --- | --- | --- |
| 閃光輸出 | 只有全光輸出：GR III 無法控制 GF-2 | 搭配 GF-2 時，全光或四分之一輸出（閃光量 1/1 或 1/4），並分別計算曝光 |
| 閃光指數 | 固定為 3，即 GF-2 的閃光指數 | 3，或您自己閃光燈的閃光指數（1 到 90） |
| 使用 ISO 自動時的近距離主體 | 距離小於 0.7 m 時，最多約亮 1 EV | 依距離所需的光圈，最小到 f/16 |
| 開啟 ND濾光鏡時使用 ISO 自動 | 背景會暗兩級 | 快門速度會將 ND濾光鏡納入考量，因此背景曝光正確 |
| 明亮光線下的極近主體 | 可能要求 f/19，超出鏡頭的 f/16 | 保持在 f/2.8–f/16 之內 |
| 閃光同步 | 可能要求比閃光同步更快的快門速度 | 始終在閃光同步範圍內；GR IV 的閃光同步速度取決於光圈 |
| 其他一切 | 開啟此模式會取代一般的閃光行為 | 是五個閃光燈模式選項之一：隨時切回強制閃光，即可使用 GR IV 的自動閃光量 |

已檢查超過 250,000 種距離、ISO、ND濾光鏡、閃光燈模式、光線、閃光燈類型和閃光指數（1 到 90）的組合。沒有任何一種會要求 f/2.8–f/16 以外的光圈、超出您限制的 ISO，或閃光燈無法同步的快門速度。

## 開始之前

- **相機：** RICOH GR IV（標準彩色機型）。不支援其他機型。
- **閃光燈：** RICOH GF-2，或您知道其閃光指數的手動閃光燈（見[使用自己的閃光燈](#使用自己的閃光燈)）。其他閃光燈模式則與先前一樣，適用於所有閃光燈。
- **您的相機必須已更新至韌體 1.11。** 請在相機設定選單中確認版本。
  - 較舊版本：先以一般方式，用 RICOH 的官方檔案更新至 1.11。
  - 較新版本：**請勿使用本工具。** 本工具只支援 1.11。
- **官方韌體檔案。** 從 RICOH IMAGING 官方 GR IV 支援頁面下載**韌體版本 1.11**。如有需要請解壓縮，直到取得 **`fwdc248b.bin`** 檔案。
- **充飽電的電池。** 韌體更新過程中絕不能斷電。
- **一張可以格式化的 SD 卡。**
- **一台安裝 Python 3.8 或更新版本的電腦。** macOS 和大多數 Linux 系統已內建；在 Windows 上，請從 python.org 安裝。不需要其他任何東西。
- 記下您不想重新設定的自訂設定（C1、C2 等）。

## 製作韌體

在此資料夾中開啟終端機並執行（請使用您儲存官方檔案的路徑）：

```sh
python3 gr4_gf2unlock.py patch ~/Downloads/fwdc248b.bin
```

在 Windows 上：

```bat
py gr4_gf2unlock.py patch C:\Users\you\Downloads\fwdc248b.bin
```

工具會先確認您提供的是真正的官方 1.11 檔案，接著產生 GF-2閃光燈模式韌體並加以檢查。這大約需要一分鐘。一切正確時，結尾如下：

```
wrote output/fwdc248b.bin  (SHA-256 86abac009d3664ede49ef912073d00b8fb15ac7e9867265aecda581c932db41a)
```

若有問題（例如韌體版本不同、檔案已被修改過，或下載的檔案損毀），工具會顯示 `refused: …`，且**不寫入任何內容**。

### 使用自己的閃光燈

GF-2閃光燈模式是依 GF-2 的閃光指數 3 規劃曝光。若要使用其他閃光燈，請用 `--gn` 加上它的閃光指數：

```sh
python3 gr4_gf2unlock.py patch ~/Downloads/fwdc248b.bin --gn 12
```

- **適用的閃光燈：** 任何不與相機通訊、由熱靴中央接點觸發的閃光燈：手動閃光燈，以及大多數為其他相機品牌製造的閃光燈。P-TTL 閃光燈，或設為 P-TTL 模式的相容閃光燈，會與相機通訊；此時 GF-2閃光燈模式的運作與強制閃光相同，與 GR III 相同。
- 請填入閃光燈說明書上全光輸出時**ISO 100、以公尺為單位**的閃光指數。若閃光指數以英尺為單位：除以 3.3。變焦閃光燈：請使用您拍攝時的焦段所對應的閃光指數。
- 允許範圍：**1 到 90**。相機以 1/16 級為單位運算，工具會顯示實際採用的數值，例如 12 會顯示 `guide number: 11.81`。
- **相機無法設定這類閃光燈的輸出。** 請將閃光燈設為**全手動輸出**，並將閃光量設為**自動**或 **1/1**。若改將閃光燈設為 1/4 輸出，也請將閃光量設為 **1/4**：相機便會以少兩級來規劃曝光。
- 工具會先製作標準韌體並如上檢查，然後只更改閃光指數。因此 SHA-256 會與上面的不同；`check` 會顯示檔案的閃光指數。
- 若要更改閃光指數，請重新製作韌體並安裝。

## 安裝到相機

### 1. 複製到 SD 卡

1. **在相機中格式化 SD 卡。**
2. 將 **`output/fwdc248b.bin`** 複製到記憶卡的**最上層**：不要放進資料夾，檔名必須完全保持 `fwdc248b.bin`。

### 2. 更新相機

1. 裝入充飽電的電池和 SD 卡。
2. 依照 RICOH 官方 GR IV 韌體更新說明，從相機設定選單開始韌體更新。
3. **相機會顯示從版本 1.11 更新到版本 1.11。** 這是正常的：GF-2閃光燈模式韌體保留原本的版本號碼。請確認更新。

> [!CAUTION]
> 在更新完成且相機重新啟動之前，**請勿關閉相機、打開電池蓋或記憶卡蓋，也不要取出記憶卡**。

### 3. 拍攝

1. 在相機和 GF-2 都**關閉**的狀態下，將 GF-2 完全推入熱靴，然後開啟兩者。
2. 拍攝選單 → **閃光燈模式** → **GF-2閃光燈模式**。
3. 將**閃光量**設為**自動**或 **1/1**（全光輸出），或設為 **1/4**。
4. 對焦在主體上並拍攝。

- 韌體版本仍顯示 **1.11**，這是正常的。
- 從記憶卡刪除 `fwdc248b.bin`（或格式化記憶卡），以免不小心再次開始更新。

### 還原官方韌體

> [!IMPORTANT]
> **請先將閃光燈模式設為 GF-2閃光燈模式以外的任何選項**，例如強制閃光，並在每個使用它的自訂模式（C1、C2 等）中做同樣的設定。官方韌體沒有 GF-2閃光燈模式設定。

接著改用 RICOH 的**官方** `fwdc248b.bin` 重複步驟 1–2。相機同樣會顯示 **1.11 → 1.11**；確認後，相機就恢復原廠狀態。

## 須知

- **裝上或取下閃光燈之前，請先關閉相機和 GF-2**，並將 GF-2 完全推入熱靴。
- **相機無法得知閃光燈是否會閃光。** 選擇 GF-2閃光燈模式時，即使閃光燈已關閉、未裝上或仍在回電，相機仍會依閃光拍攝來設定曝光，這樣的照片會太暗。GR III 也是如此。
- **近距離使用輸出強的閃光燈：** 主體近到即使用 f/16 和最低 ISO，進入的閃光仍然過多時，照片會比規劃的更亮。使用 ISO 自動且 ND濾光鏡設為自動時，相機在偏亮約一級時會加上 ND濾光鏡。否則請使用閃光量 1/4，或後退一些。
- **固定 ISO 與遠處主體：** 光圈全開（f/2.8）之後，主體越遠就越暗。請提高 ISO，或使用 ISO 自動。
- **明亮的日光：** 快門速度無法快於閃光同步速度（f/2.8–f/4 時為 1/2500 秒）。ND濾光鏡設為自動時，若光線遠比這更亮，相機會使用 ND濾光鏡。此時閃光燈的作用是補光。
- **連環拍攝：** 與 GR III 不同，相機不會自動等待閃光燈回電。每次閃光拍攝之間請間隔約兩秒。
- **快拍距離優先自動曝光、B 和 T，以及影片**的運作與先前相同。GF-2閃光燈模式不適用於這些情況。
- **無法與 GR4-MonoUnlock 或 GR4-XPanUnlock 合併使用。** 每個工具都從官方韌體開始，而本工具不接受它們的檔案。
- **從較早的 GR4-GF2Unlock 更新：** 以相同方式安裝新檔案即可，不需要先還原為官方韌體。1.1.0 和 1.2.0 版只將 GF-2閃光燈模式套用於相機偵測得到的閃光燈，因此搭配手動閃光燈時沒有作用；1.3.0 已修正此問題。
- **RICOH 官方更新會移除 GF-2閃光燈模式。** 它會取代整個韌體。請先設定其他閃光燈模式（見[還原](#還原官方韌體)）。
- **只適用於標準版 GR IV。** 絕對不要將此檔案安裝到其他機型。
- **送修相機之前**，請先還原官方韌體。

### 檢查韌體檔案

將任何韌體檔案複製到記憶卡之前：

```sh
python3 gr4_gf2unlock.py check path/to/fwdc248b.bin
```

它會告訴您該檔案是官方 1.11、本工具製作的 GF-2閃光燈模式版本（並附上其閃光指數），還是其他檔案（它也能辨識 GR4-GF2Unlock 1.0.0、1.1.0 和 1.2.0，以及 GR4-MonoUnlock 和 GR4-XPanUnlock 的檔案）。

## 風險

- 相機無法分辨良好的韌體檔案和損毀的檔案。只將工具寫入的檔案（或經 `check` 確認的檔案）複製到記憶卡。
- 若更新中斷，或韌體檔案無法啟動，相機可能無法再進入更新功能，屆時就需要 RICOH 維修。測試中沒有發生過這種情況，但無法排除。
- 在仍選擇 GF-2閃光燈模式的狀態下還原官方韌體，尚未經過測試。請先設定其他閃光燈模式。
- 相機本身的校正資料不會被更動。
